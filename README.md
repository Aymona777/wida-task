# شركة هورايزون لخدمات الأعمال (Horizon B2B Services)
## المنظومة الذكية لمعالجة وتصنيف طلبات العملاء وحوكمة الامتثال (AI Assistant Workflow)

---

## 🌟 نظرة عامة على المشروع (Project Overview)

تم بناء هذه المنظومة المتكاملة كحل ذكي متطور لشركة **هورايزون لخدمات الأعمال (Horizon B2B Services)** بهدف أتمتة استقبال وتحليل طلبات العملاء، ومطابقتها مع **دليل الخدمات الثمانية المعتمدة**، وتطبيق **سياسات التشغيل وضوابط الامتثال الصارمة**، وتوليد **الملخص الداخلي الموحد (04_Output_Template)** ومسودة الرد المهني للعميل، مع توفير **بوابة مراجعة بشرية (Human-in-the-Loop)** لحوكمة الاعتماد قبل الإرسال النهائي.

---

## 🚀 المتطلبات الأساسية المحققة (Fulfilled Requirements)

| # | المتطلب | آلية التنفيذ والتحقيق في المنظومة |
|---|---|---|
| **1** | **استقبال ومعالجة الطلبات (Request Reception)** | دعم الإدخال النصي المباشر، ورفع الملفات بصيغ متعددة (`.txt`, `.pdf`, `.docx`, `.json`, `.csv`)، والتحميل الفوري للنماذج التدريبية الرسمية A - E. |
| **2** | **استخراج البيانات والكيانات (Data Extraction)** | استخراج اسم الجهة، واسم وصفة مسؤول التواصل، ووسائل الاتصال (الهاتف/البريد)، وحالة ورقم السجل التجاري، والاحتياج الدقيق، والموعد المطلوب، وحصر البيانات الناقصة. |
| **3** | **مطابقة دليل الخدمات (8 Services Matching)** | مطابقة ذكية مع الخدمات الثمانية المعتمدة، وتحديد الخدمة الأساسية والخدمة الثانوية مع التعليل الدقيق. |
| **4** | **تطبيق سياسات التشغيل (Policy Enforcement)** | التحقق الصارم من شرط السجل التجاري (سياسة 1)، والحد الأدنى للتنفيذ 3 أيام عمل (سياسة 2)، ورصد المواعيد العاجلة التي تقل عن المعدل القياسي (سياسة 3)، ومنع التسعير الآلي أو قبول العمل المجاني (سياسة 7). |
| **5** | **توليد النموذج الموحد (Output Formatting)** | بناء الملخص الداخلي الموحد المطابق 100% لنموذج `04_Output_Template.txt`، وتوليد مسودة رد بريد إلكتروني مخصصة بالعربية. |
| **6** | **قاعدة بيانات مهيكلة ومؤتمتة (Data Store)** | حفظ تلقائي في قاعدة بيانات SQLite مع دعم التصدير الفوري إلى ملفات Excel (`.xlsx`) بتنسيق RTL ملوّن، و CSV (بترميز UTF-8 BOM)، و JSON. |
| **7** | **منع الهلوسة والطلبات خارج النطاق (Zero Hallucination)** | الرصد الحاسم للطلبات التي تقع خارج نطاق الشركة (مثل التسويق الرقمي وإدارة حسابات التواصل والإعلانات والمؤثرين في الطلب C)، وصياغة اعتذار مهني دون اختلاق خدمات أو وعود وهمية. |
| **8** | **المراجعة البشرية والاعتماد (Human-in-the-Loop)** | بوابة مراجعة مخصصة بنظام الشاشة المقسمة (Side-by-Side Review Workbench) تتيح للموظف المسؤول تعديل التصنيف أو طلب استيضاح أو الاعتماد النهائي مع سجل تدقيق زمني كامل (Audit Trail). |

## 🏛️ دليل الخدمات الثمانية لشركة هورايزون (Service Catalog)

1. **الاستشارات الإدارية والتحول التشغيلي** (10 إلى 15 يوم عمل)
2. **أتمتة العمليات والحلول الذكية** (5 إلى 10 أيام عمل)
3. **تطوير البرمجيات والأنظمة المخصصة** (15 إلى 30 يوم عمل)
4. **البنية التحتية السحابية والأمن السيبراني** (5 إلى 7 أيام عمل)
5. **تحليل البيانات ولوحات ذكاء الأعمال** (4 إلى 8 أيام عمل)
6. **التدريب وبناء القدرات الرقمية** (3 إلى 5 أيام عمل للتحضير)
7. **التكامل والربط بين الأنظمة** (5 إلى 12 يوم عمل)
8. **الدعم الفني والصيانة التشغيلية** (حسب نطاق العطل واتفاقية مستوى الخدمة SLA)

## 💻 تعليمات التشغيل السريع (Quick Start Guide)

### 1. تشغيل واجهة الويب التفاعلية (Web Application)
لتشغيل الخادم وفتح لوحة التحكم الرسومية في المتصفح تلقائياً:
```powershell
python run_server.py
```
سيعمل النظام على الرابط: `http://127.0.0.1:8000`

### 2. تشغيل جناح الاختبارات المعيارية (Run Benchmark Tests)
للتحقق الآلي من سلامة جميع القواعد والسياسات الـ 11:
```powershell
python run_tests.py
```

### 3. استخدام أداة سطر الأوامر (CLI Tool)
لمعالجة أي طلب من الطرفية مباشرة:
```powershell
# معالجة النموذج A
python run_cli.py --sample A

# معالجة ملف خارجي
python run_cli.py --file path/to/request.txt

# تصدير السجلات إلى إكسل
python run_cli.py --export excel
```

## 🛡️ ميزات الأمان وحوكمة الجودة (Security & Governance)
- **Zero Hallucination Guarantee:** محرك استنتاجي دقيق يمنع اختلاق معلومات غير موجودة في الطلب أو تقديم أسعار خارج الصلاحية.
- **Audit Trail & Traceability:** توثيق كل عملية إنشاء، تحليل، تعديل، واعتماد مع تسجيل اسم المراجع والتوقيت الزمني.
- **Data Privacy:** معالجة البيانات محلياً مع تشفير التخزين وضمان عدم تسريب بيانات الشركات.
